# Turma do Kako Social Publisher Media

This public repository delivers final media approved for public distribution by Turma do Kako.

It contains no source masters, editorial drafts, prompts, audience data or credentials. Generated files remain available only during the active publishing and recovery window.

The `main` branch documents the repository. The disposable `gh-pages` branch contains the current public media snapshot.

Published files use opaque content-hash paths. A daily GitHub Actions job removes files after their queue and recovery window expires.
